# PCUI 桌面工作区排版系统设计

## 目标

在不改变现有配色和页面结构的前提下，建立适合大众用户、Windows WebView2 和中英文界面的固定排版系统。重点解决当前字体未实际加载、控件与表格普遍使用 16px 导致层级扁平、局部 10–11px 又过小，以及行高和字重不统一的问题。

## 选择方案

采用“舒适清晰”方案。它比紧凑后台更容易阅读，又不会像大字模式那样降低桌面信息密度。排版使用固定 `rem`，不使用随窗口变化的流式字号。

### 字体栈

```css
"Segoe UI Variable", "Segoe UI", "Microsoft YaHei UI", "PingFang SC",
system-ui, -apple-system, BlinkMacSystemFont, sans-serif
```

WebView2 在 Windows 上优先使用 Segoe UI Variable；中文明确回退到 Microsoft YaHei UI。macOS 开发环境使用 PingFang SC。项目不下载网络字体，从而避免离线失效、字体闪烁和布局跳动。

### 字号与行高

| 语义角色 | 字号 | 行高 | 主要用途 |
| --- | ---: | ---: | --- |
| Caption | `0.75rem` / 12px | `1.125rem` / 18px | 时间、快捷键、非关键辅助信息 |
| UI | `0.875rem` / 14px | `1.25rem` / 20px | 导航、按钮、表格、筛选、字段标签 |
| Body | `1rem` / 16px | `1.5rem` / 24px | 正文、说明和需要连续阅读的内容 |
| Section | `1.25rem` / 20px | `1.75rem` / 28px | 面板标题、详情标题 |
| Page | `1.75rem` / 28px | `2.25rem` / 36px | 页面一级标题 |

数据指标允许使用 `1.5rem` / 24px、30px 行高，作为数字内容的专用例外。

### 字重与细节

- `400`：正文、表格普通单元格、辅助说明。
- `500`：导航、按钮、表头、字段标签、列表主文本。
- `600`：页面与面板标题、关键数字。界面不再依赖浏览器默认 `strong` 的 700 字重。
- 页面标题使用 `-0.02em` 字距，其余正文保持正常字距。
- 表格数字、百分比、时间和指标启用 `tabular-nums`。
- 正文最大阅读宽度为 `68ch`；表格和结构化数据不受此限制。

## 应用范围

1. 在全局 CSS 中定义语义排版令牌和基础字体渲染设置。
2. 统一 PrimeVue Button、InputText、Select、DataTable、Dialog、Tabs 的基础字号与行高。
3. 将侧栏、顶栏、搜索结果、表格和字段标签统一为 14px UI 层级。
4. 页面说明保持 14px 次要文本；长正文、消息正文和 AI 对话使用 16px Body 层级。
5. 页面标题保持 28px，面板标题提升为 20px；卡片内部小标题根据密度使用 16px 或 14px。
6. 移除 9–11px 的关键文字。通知角标等极小空间例外必须提供无障碍名称。

## 响应式与无障碍

- 桌面产品使用固定字号，窄窗口只改变布局，不缩小文字。
- 支持浏览器 200% 缩放，不产生水平页面溢出；表格区域可在必要时独立滚动。
- 浅色和深色主题均保持正文与辅助文字对比度。
- 输入、按钮和导航继续继承用户默认字体大小，不禁用浏览器缩放。

## 验证

- 单元测试检查语义排版令牌存在且关键组件使用对应角色。
- TypeScript 类型检查与生产构建必须通过。
- 在 1440、1280、1024 宽度检查工作台、文件、项目、消息和设置页面。
- 分别检查中文、英文、浅色、深色以及 200% 缩放。
- 使用浏览器计算样式确认页面标题 28px、正文 16px、常规 UI 14px、辅助文字不低于 12px。

## 非目标

- 本轮不更换 PrimeVue、导航结构或页面信息架构。
- 本轮不引入在线字体、展示字体或第二字体家族。
- 本轮不调整品牌主色与图表配色。
