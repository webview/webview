# PCUI 桌面工作台设计规格

## 目标

从空目录创建一个可长期扩展的 Vue 3 PC 应用界面框架。应用由 WebView2 承载，视觉定位为精致明亮的现代 SaaS 桌面工具，首版提供完整导航、主题、国际化、窗口控制桥接和十二组标准示例页面。

## 技术方案

- Vue 3、TypeScript、Vite，使用 Composition API 和 `<script setup>`。
- PrimeVue 4 提供表单、表格、菜单、弹窗、通知等复杂交互组件。
- Tailwind CSS 4 负责布局、间距、响应式和页面级视觉细节。
- PrimeVue Aura Preset 通过 Design Tokens 调整品牌色和组件语义色。
- Vue Router 管理页面、面包屑和菜单状态。
- Pinia 管理应用偏好、用户信息和通知状态。
- Vue I18n 提供 `zh-CN` 与 `en-US`，应用文案不得散落硬编码。
- ECharts 提供数据分析图表，并通过独立图表组件封装。

PrimeVue 与 Tailwind 共享 `.app-dark` 深色选择器。主题状态支持浅色、深色、跟随系统三种模式，并持久化用户选择。

## 应用布局

默认布局由可伸缩左侧导航、顶部工具区、中央路由内容区和按需右侧上下文面板组成。

左侧导航展开宽度约 240px，收起宽度约 72px。收起后保留图标、选中状态和悬停提示。顶部工具区包含面包屑、全局搜索、快捷创建、语言、主题、消息和账户入口。

WebView2 使用无边框窗口时，顶部空白区域可作为拖拽区域。最小化、最大化/还原和关闭按钮融入右上角工具区，不单独创建传统标题栏。可交互区域必须排除拖拽命中。双击顶部空白区域切换最大化状态。

较窄窗口下，侧栏自动进入图标模式，右侧上下文面板改为抽屉。首版针对 PC 窗口进行优化，同时保证 1024px 宽度下可正常使用。

## WebView2 边界

前端只依赖统一的 `windowBridge` 接口：

- `minimize()`
- `toggleMaximize()`
- `close()`
- `isMaximized()`
- `onWindowStateChanged(callback)`

桥接层负责适配 WebView2 Host Object 或 WebMessage。普通浏览器中使用安全的空实现，开发预览不报错。页面和布局组件不得直接访问具体 Host Object。

## 视觉系统

视觉语言为轻盈、专业、精致的现代 SaaS 工作台。浅色主题是默认主题，侧栏与内容区保持明亮统一，不使用大面积深色导航。

配色比例约为：

- 70% 中性背景与留白。
- 20% 卡片、侧栏、浮层等层级表面。
- 10% 品牌色与语义状态色。

基础色建议：

- 品牌主色 `#4F6BED`。
- 浅色应用背景 `#F6F8FC`。
- 卡片表面 `#FFFFFF`。
- 主文本 `#172033`。
- 次级文本 `#647089`。
- 边框 `#E6EAF2`。
- 成功 `#16A36A`、警告 `#E59A18`、危险 `#E5484D`。

深色主题使用蓝灰色表面，不使用纯黑。卡片以边框建立层级，阴影只用于浮层和需要提升层级的对象。卡片主圆角约 14px，按钮和输入框约 10px。交互动效控制在 160–240ms，并尊重减少动画的系统偏好。

## 页面范围

1. 工作台概览：指标、趋势、今日任务、最近项目。
2. 项目管理：搜索筛选、表格/卡片视图、项目详情抽屉。
3. 任务中心：看板与列表视图、优先级、负责人和状态。
4. 文件管理：文件夹树、文件列表、上传进度和文件操作。
5. 数据分析：时间筛选、核心图表和数据明细。
6. 团队成员：成员列表、角色、状态和邀请弹窗。
7. 消息中心：分类列表、消息详情和已读状态。
8. 日历日程：月/周视图和日程编辑弹窗。
9. AI 助手：会话侧栏、聊天区、快捷提示和输入区。
10. 个人中心：个人资料、偏好和安全设置。
11. 系统设置：外观、语言、通知和快捷键设置。
12. 登录与异常：登录、404 和无权限页面。

示例数据通过本地服务层提供，页面不得直接内嵌大段数据。服务接口保持异步形态，后续可替换为真实 API。

## 组件与目录边界

```text
src/
├─ assets/
├─ components/
│  ├─ base/
│  ├─ common/
│  └─ charts/
├─ layouts/
├─ views/
├─ router/
├─ stores/
├─ composables/
├─ locales/
├─ services/
├─ bridge/
├─ types/
├─ config/
└─ styles/
```

布局组件只处理应用壳层。页面组件负责页面编排。筛选器、表格、看板、弹窗、表单和图表拆成可独立理解的局部组件。路由元数据统一维护标题、图标、权限标识、面包屑与菜单状态。

公共组件至少包含标准页头、状态标签、空状态、加载状态、错误状态、确认弹窗和响应式数据容器。复杂 PrimeVue 组件仅在存在稳定的项目级默认值时进行薄封装，避免无意义的二次 API。

## 状态与数据流

- `appStore`：侧栏状态、主题、语言和窗口状态。
- `userStore`：当前用户、身份和偏好。
- `notificationStore`：消息列表、未读数量和操作状态。
- 页面业务数据通过 `services` 获取并保留在页面或领域 composable 中。
- 用户偏好写入 localStorage；主题与语言在应用启动前尽早恢复，避免闪烁。

## 国际化

导航、路由标题、按钮、空状态、验证文案和示例内容均提供中文与英文。语言切换同时更新 Vue I18n、PrimeVue Locale、HTML `lang` 和日期格式。新增页面必须以翻译键作为可见文案来源。

## 错误与状态处理

异步页面均具备加载、空数据和失败状态。失败状态提供明确原因和重试操作。全局异常由应用级错误边界记录并显示非阻塞反馈。WebView2 桥接不可用时只禁用真实窗口操作，不影响页面浏览。

## 可访问性

所有图标按钮提供可访问名称。导航、弹窗、菜单和表单优先使用 PrimeVue 的可访问交互。键盘可到达主要功能，焦点样式清晰，正文与交互文本达到 WCAG AA 对比度。颜色不作为状态的唯一表达方式。

## 验证标准

- 类型检查和生产构建通过。
- 关键 stores、主题 composable、语言切换和 windowBridge 具备单元测试。
- 布局可完成侧栏展开/收起、浅色/深色切换、中英文切换。
- 十二组路由均可访问，包含标准页面结构和代表性 PrimeVue 组件。
- 普通浏览器预览不会因缺少 WebView2 Host Object 报错。
- 在主流 PC 宽度和 1024px 窗口下无关键内容重叠或横向溢出。

## 非目标

首版不接入真实后端、认证服务、文件上传服务或 AI 服务，不实现细粒度权限管理，不实现 WebView2 宿主端 C# 代码。首版只提供清晰的前端接口和可替换的模拟服务。
